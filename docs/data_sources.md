# Data sources and provenance

## Food Delivery dataset

- Hugging Face dataset mirror: https://huggingface.co/datasets/aneesarom/Food-Delivery
- The notebook describes the dataset as associated with a publicly shared Zomato Delivery Operations dataset on Kaggle.
- The project has not independently verified that this is an official Zomato production-data release. Do not describe it as proprietary company data or claim affiliation with Zomato.
- The source dataset has 45,584 rows across the train and test splits: 36,467 source-training records and 9,117 source-test records in this project run.

## Derived data

`fulfillment_pulse_test_predictions.csv` is generated by Notebook 02. It represents the 9,117 source test rows, with the features used by the model plus actual delivery time, predicted delivery time, signed error and absolute error. It is a derived evaluation export, not an additional independent dataset.

## Definitions

- Delivery duration target: source field `Time_taken (min)`, renamed to `actual_minutes` in the prediction export.
- Signed error: `actual_minutes - predicted_minutes`. Positive error means the model underpredicted the actual duration; negative error means it overpredicted.
- Distance: Haversine great-circle distance computed from restaurant/customer coordinates, not road-network route distance.
- Five-minute prediction metric: percentage of held-out predictions where absolute error is less than or equal to five minutes; this is not an operational delivery SLA.
