## Root files

- `README.md`: recruiter-facing project overview, objectives, results, technology, setup and limitations.
- `requirements.txt`: Python packages used by the notebooks.
- `.gitignore`: excludes local environments, SQLite database files, raw/derived CSV exports and temporary outputs from Git.

## `notebooks/`

- `01_data_ingestion_quality_audit.ipynb`: first executed notebook. Loads the two source splits for exploratory auditing, reviews the schema and missingness, checks suspicious ages/ratings/coordinates and summarises delivery time and operating categories. It saves a raw snapshot and a data-quality report in its runtime.
- `02_delivery_time_prediction.ipynb`: final executed/fixed modelling notebook. Reloads the official source splits independently, applies documented cleaning and feature engineering, compares baseline/Ridge/Random Forest/HistGradientBoosting models, selects on validation MAE, evaluates on the separate source test split, generates permutation importance and exports artifacts.

The notebook filenames are normalised for the repository. They are copies of the executed notebooks used during this project; keep the executed outputs when committing so reviewers can inspect the results without rerunning immediately.

## `data/`

- `raw/`: optional local source downloads. Do not commit raw data unless redistribution permissions and dataset terms have been checked.
- `processed/`: optional intermediate or cleaned data files generated by notebooks.
- `exports/`: expected location for `fulfillment_pulse_test_predictions.csv`, which the SQL loader consumes and which can also be used for Power BI refresh.
- `README.md`: explains how to reproduce/download the data and why data files are ignored by Git.

The directory scaffold does not contain the user's data exports. Obtain `fulfillment_pulse_test_predictions.csv` from the output ZIP generated by Notebook 02.

## `scripts/`

- `load_predictions.py`: standard-library Python CSV importer. Validates the expected 20 columns, normalises null tokens, loads values into SQLite table `delivery_predictions`, creates indexes and checks the loaded row count.

## `sql/`

- `schema.sql`: table schema and indexes for the prediction export.
- `business_analysis.sql`: 13 queries covering data validation, model performance, traffic, weather, traffic/weather combinations, order type, city category, concurrent deliveries, courier-rating bands, prediction direction, error bands, distance bands and a project-defined 30-minute threshold.
- `README.md`: explains how to load the data and run the SQL analysis, metric definitions and interpretation cautions.

## `models/`

- `fulfillment_pulse_eta_model.joblib`: fitted HistGradientBoosting preprocessing/model pipeline exported by Notebook 02. It is not included in this scaffold; copy it from `fulfillment_pulse_outputs.zip` after downloading the notebook outputs. Only load this trusted project artifact.

## `dashboard/`

- `Fulfillment_Pulse.pbix`: copy the final Power BI Desktop report here after saving it locally.
- `screenshots/`: static report previews included for GitHub visitors who cannot open PBIX in the browser. The two PNG previews in this scaffold come from the supplied report screenshots.

## `reports/`

- `model_evaluation.md`: validation-vs-test results, selected model and interpretation of MAE/RMSE/R².
- `business_insights.md`: descriptive patterns currently visible in the dashboard, with room to append verified SQL findings after analysis.

## `docs/`

- `methodology.md`: task definition, prediction-time assumption, data cleaning and feature-engineering pipeline, model selection and evaluation approach.
- `data_dictionary.md`: definitions and types of the 20 exported prediction fields.
- `data_sources.md`: public dataset mirror, attribution caveat and metric/distance definitions.
- `reproducibility.md`: practical steps to rerun notebooks, export artifacts, build the SQLite database and refresh Power BI.

## Generated locally; do not commit by default

- `.venv/`, `__pycache__/`, Jupyter checkpoints and temporary logs.
- `fulfillment_pulse.db` and SQLite journal/WAL files.
- Raw source data, processed CSVs and prediction-level exports.
- Temporary notebook output ZIPs.

The final `.pbix` and `.joblib` artifacts may be committed if their size and repository policy are suitable. Confirm the final report/model artifacts are the intended versions before adding them to Git.
