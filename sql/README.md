# SQL analysis (SQLite)

## Input and scope

The SQL database is built from `data/exports/fulfillment_pulse_test_predictions.csv`, the Notebook 02 held-out test prediction export. Expected row count: 9,117. It is not the full 45,584-row source dataset.

## Files

- `schema.sql`: SQLite `delivery_predictions` table schema and indexes.
- `business_analysis.sql`: 13 SQL queries.
- `../scripts/load_predictions.py`: CSV-to-SQLite loader using only the Python standard library.

## Load data

From the repository root:

```bash
python scripts/load_predictions.py "data/exports/fulfillment_pulse_test_predictions.csv"
```

This creates/replaces `fulfillment_pulse.db` in the repository root. It validates the expected 20 column names, normalises null tokens, inserts records in batches, creates indexes on traffic, weather and city, and verifies the loaded count. The `row_id` is generated by SQLite and is not an original order identifier.

## Queries included

1. Data-quality validation and target range.
2. Overall delivery/model performance, mean bias and <=5-minute prediction tolerance.
3. Performance by traffic density.
4. Performance by weather.
5. Traffic/weather combinations (minimum 20 observations per group).
6. Performance by order category.
7. Performance by city category.
8. Performance by number of concurrent deliveries.
9. Courier-rating bands.
10. Underprediction vs overprediction direction.
11. Absolute prediction-error bands.
12. Haversine distance bands, retaining unavailable distance records.
13. Share of test orders above a project-defined 30-minute threshold.

## Interpretation rules

- `error_minutes = actual_minutes - predicted_minutes`.
- Positive signed error means the model underpredicts duration; negative means overprediction.
- MAE is the average of `absolute_error_minutes`.
- The five-minute threshold describes prediction error, not a delivery SLA.
- The 30-minute threshold is an analytical cut-off chosen for this project, not a company service commitment.
- Group differences are descriptive associations, not causal effects.
- Missing categories should remain visible as `Unknown` in summary queries.
- The `distance_km` field is a straight-line Haversine estimate, not road route distance.
