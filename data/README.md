# Data directory

The project uses the public `aneesarom/Food-Delivery` Hugging Face dataset (45,584 source records across source train/test splits). The dataset is loaded directly in both notebooks.

## Subfolders

- `raw/`: optional downloaded source snapshots.
- `processed/`: optional intermediate data created during cleaning/feature engineering.
- `exports/`: Notebook 02 exports used by SQL and Power BI.

## Required SQL input

Place this file in `data/exports/`:

`fulfillment_pulse_test_predictions.csv`

It is generated by Notebook 02 and contains the 9,117 held-out test rows, 16 model input features and four prediction/result fields. The SQL loader expects the exact 20 headers documented in `docs/data_dictionary.md`.

The raw dataset and CSV exports are ignored by Git by default. This keeps the repository small and avoids redistributing third-party data without checking the relevant terms. A reviewer can reproduce the outputs by running the notebooks and following their export steps.
